💡 手機版登入運作原理說明：

當您在手機版按下「📱 手機頁面跳轉登入」後，系統會直接在原頁面跳轉至 Google 官方授權頁，完成授權後會帶回 Token 自動解析並載入雲端資料，無須開啟 Popup 彈出視窗。

🚨 手機版登入出現「已封鎖存取權 (Access Blocked)」檢測與解決清單：
  1. 【重要】禁止使用 file:// 本地檔案開啟： Google 官方 OAuth 嚴格禁止 file:// 本地檔案發起雲端連線。若您是直接打開下載的 .html 檔案，請務必將網頁部署至 GitHub Pages 或 Vercel，或透過伺服器網址開啟。
  2. 【Google Cloud Console 設定】加入「已授權的重導向 URI」： 請前往 Google Cloud 憑證設定頁，在「已授權的重導向 URI (Authorized redirect URIs)」與「已授權的 JavaScript 來源」填入您手機開網頁的完整 URL（例如：https://yourname.github.io/app.html）。
  3. 【Google Cloud Console 設定】將 Email 加入「測試使用者」： 若您的 Google Cloud 應用程式狀態為「測試中 (Testing)」，請至「OAuth 同意畫面」>「測試使用者 (Test users)」新增您的 Google Email 帳號（例如 hawk82508@gmail.com）。否則授權時 Google 就會顯示「已封鎖存取權」！
  4. 【瀏覽器環境】切換至手機系統瀏覽器： 請勿在 LINE、FB、微信內建瀏覽器內直接點選連線。請點右上方「...」選擇「在 Safari 開啟」(iOS) 或「在 Chrome 開啟」(Android)。
